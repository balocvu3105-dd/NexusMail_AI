# Purpose

This document defines every API design rule for NexusMail AI.

Every API generated by AI must comply with this guide.

---

# API Philosophy

APIs represent business capabilities.

APIs are contracts.

APIs must remain stable.

Breaking changes require a new API version.

# REST Principles

Resources are nouns.

Actions are HTTP verbs.

Correct

/api/v1/users

/api/v1/workspaces

Incorrect

/getEmails

/deleteEmail

/createUser

/sendNotificationNow
